# Movement body and collider reconstruction

[I] These four files add concrete C++20 analysis functions and owned synthetic fixtures. They do not declare a live Rust/Unity ABI, execute sample instructions, perform game calls, or implement a stack-spoof executor. [C] Numeric addresses are keys into `Snapshot`; all unknown call results and effects cross typed callbacks or supplied predicate inputs.

[C] Primary evidence is [32cea8.asm](/home/john/Desktop/cheat_re/dump_analysis/semantic_reconstruction/05_server/32cea8.asm) and [322aec.asm](/home/john/Desktop/cheat_re/dump_analysis/semantic_reconstruction/01_hooks/322aec.asm). [C] Helper interpretations were cross-checked against `dump_analysis/static/cheat_annot.asm`. [C] No input/binary or external analysis directory was modified and no network endpoint was contacted.

### Tick control flow

- [C] 0x32cec2..0x32cf58: owned lazy bits 1/2, original target and dispatch slot 0x3f8480; original record 0x3f0888. Bits are set before callbacks. [U] Metadata lookup and dispatch implementations remain typed dependencies.
- [C] 0x32cf5d..0x32cfb4: caller equality, predicate 0x2e0e4c, numeric range checks on 0x2e069c and 0x2dda9c results. A caller mismatch returns without querying clocks; matching-caller guard exits refresh both clocks.
- [C] 0x32cfba..0x32cff5: first `0x31581c()-0x3f2124` read uses MINSS with literal 1.0 followed by lower clamp 0.0, storing 0x3d72ec. A second clock read produces independent **unclamped** elapsed time for candidate validation, velocity and the two limiters. Quiet NaN in the first read selects 1.0, as MINSS does.
- [C] 0x32d004..0x32d167: SpecialTeleport obtains the target before reading player+0x4e8. With a valid field, active manipulation and range-valid target, it clears list 0x248eb8 and constructs 25 candidates `base + (0,n*0.2,0)`, n=1..25. Each candidate gets a fresh mask and query from candidate+(0,1.5,0) to base, with scalar arguments 0/0. A range-valid current record requires `validate_movement_3226b0`; an invalid record bypasses that validation. Successful values are appended by value.
- [C] 0x32d16d..0x32d30f: a previously committed special latch skips endpoint work after candidate rebuilding. Otherwise a nonempty list yields last+(0,1.5,0). Target points 0x37 and 0x36 construct `(point37.x,point36.y+0.05,point37.z)`; the endpoint is target position or that point+(0,2,0) when Pierce is set. Two lazy queries use fresh masks. The second query is skipped when the first fails.
- [C] 0x32d315..0x32d411: a valid captured correction object enables list replay: obtain transform, set position, obtain state, conditionally set flag 0x10, call 0x32a9f8 with fourth argument false, then 0x36ace0. The loop rechecks list length after callbacks. Even an invalid correction object commits the special latch after successful queries. The final update/counter reset/0x3f8559 write runs once. Failed endpoint queries clear 0x3f8558. [C] 0x32d413..0x32d42f clears all three special flags/list when manipulation or target fails; an invalid player+0x4e8 skips this reset entirely.
- [C] 0x32d434..0x32d45a: manipulation and either desync option return false when **0.75 > clamped elapsed**. [C] 0x32d460..0x32d50a: invalid transform refreshes; the stored-position gate may call correction(true) followed by position setter, then returns false without refresh even when the vector is zero or correction object invalid.
- [C] 0x32d50f..0x32d649: reads current transform position, captures frozen position when frozen and stored position is zero, otherwise clears the stored vector when not frozen; preserves the lazy previous-state bit and transition writes. The frozen branch sets saved position, calls update, restores captured current position and returns false without refresh. The literal zero gate makes some nominal transition paths unreachable with stable globals; the branch structure is retained.
- [C] 0x32d654..0x32d7b2: interactive rising edge captures anchor and start position. Falling edge replays list 0x218960 using set-position/state flag/update, clears the start vector, and clears/returns early if the list remains nonempty. That early return precedes updating the previous-interactive latch; the next empty falling-edge call updates it. List count is read after each callback.
- [C] 0x32d7c0..0x32d8f6: computes literal clamp `clamp(5-distance((current.x,anchor.y,current.z),anchor),0,5)` into 0x3ed6b8. Interactive mode appends the current position for an empty list, or when it differs from the last and distance >0.5; stores the last item in 0x3f8458, temporarily sets anchor, conditionally sets flag 0x10, updates, restores captured current, and returns false without refresh.
- [C] 0x32d8fb..0x32d9c4: remaining frozen and invalid-record paths refresh; valid record reads +0x28 and +0x30, stores `(current-previous)/raw_elapsed` into 0x3e6060 before the unequal/unordered position gates. Both gates compare the same previous/current values; one equivalent test is used after the pure helper calculation. Equal positions therefore still perform zero-time division before skipping the limiters.
- [C] 0x32d9ca..0x32db1e: calls existing `replay_tick_limiters_32cea8`; this translation is reused. Its correction callback performs qword/dword snapshot restores **before** the lazy correction-object lookup, preserving both independent restores even when correction is invalid. [C] 0x32db25..0x32db37: a nonzero record+0x28 resets speed timer/accumulator and horizontal/vertical budgets after both validators ran. [C] 0x32db3d..0x32db5b refreshes both clocks and returns the saved original low-byte boolean.

### Collider state and restoration

[C] 0x322b0e captures `0x322ef8(object)` before lazy original setup and forwarding of all three original arguments at 0x322b86. A range-invalid captured collider still permits the original call and then skips all latch/config work. [C] The capture helper's component traversal is byte-extracted through 0x323004; [U] component lookup remains `capture_322ef8`, because class-string matching and matching-build game types are not fabricated.

[C] 0x322b9b..0x322bd7 clears shared 0x3ef841 if SmoothFlyhack is disabled, then uses `(fly && smooth_option && smooth_latch) || frozen` as the trigger argument. [C] Lazy bits 4/8 resolve and initialize Collider.set_isTrigger. The native method resolution call uses selectors -1/-1 and returns MethodInfo, whose first qword is explicitly read from `Snapshot` into the cached code-pointer key.

[C] 0x322cc5..0x322dd5 selects radius 0.38 when fly is active and shared smooth latch is false, setting 0x3f2668 after the callback. [C] 0x322dda..0x322ed7 otherwise restores 0.5 only when that latch was set, clearing it after the callback. Bits 16/32 cache the shrink setter; bits 64/128 independently resolve/cache the restore setter. [C] Both are UnityEngine.CapsuleCollider.set_radius lookups, while trigger uses UnityEngine.Collider.set_isTrigger. [U] Method/string resolution and wrapper internals are typed callbacks. No radius getter exists in this body: restoration is the constant 0.5, and the latch is shared across calls/objects.

## Math and ownership limits

[C] 0x2df5dc..0x2df606 returns true for unequal **or unordered** vector coordinates, including the alternate tail after its first return. [C] 0x2e3b58..0x2e3b83 is an exact all-zero predicate, with signed zeros equal and NaN not zero. [C] 0x2df6cc, 0x2df708 and 0x2df744 are subtraction, addition and component-wise division. [C] Distance 0x2dff30 sums squares in Y,X,Z order and calls the existing literal `sample_sqrt_2e3c88`; ideal `std::sqrt` is not substituted. [C] The clamp preserves source-operand NaNs and signed zero.

[I] `std::vector<Vec3>` owns list values rather than declaring an allocator-compatible native vector. [C] List helpers show begin/end at +0/+8, 12-byte stride, last=end-12 and clear=end=begin. [U] Native allocation/reallocation routines are not translated, and external code cannot share their live storage. The loop reads current vector length after callbacks to retain the observed traversal semantics. [I] The caller may set an explicit replay ceiling to stop fixtures with endlessly growing callbacks; reaching it reports `replay_limit` with prior mutations preserved. That limit is not attributed to native code.

[I] Out-of-copy Snapshot reads/writes report `snapshot_bounds`, retaining earlier lazy bits, calls and writes. This is an analysis safeguard; the native range predicate does not probe mapped memory. [U] Callbacks on reached branches are required; missing callbacks report the standard `std::bad_function_call` rather than inventing game behavior. Concurrency, signaling-NaN exceptions, executable ABI, physics and game/server decisions are not verified.

[U] Full 0x324b30 main movement worker remains separate future work. This pass implements neither it nor the game implementations behind callbacks. No other source/build/documentation files are part of this change.
