# Unity backend and frame controller reconstruction

[I] This unit is an offline C++20 reconstruction. Numeric addresses identify copied data or callback roles; none is converted to a host function pointer. [U] The external Unity, IL2CPP, ImGui and game implementations are not supplied by this DLL analysis. [I] A synchronous callback either supplies the required typed result or the controller stops with `missing_dependency`; successful results are never synthesized by production code.

[C] `0x3b2b6e` ORs backend flags with `0xe`; `0x3b2b85` zeros the backend user-data field. [C] Three 16-byte vertex descriptors are appended in order from `0x2ad7d0`, `0x2ad7e0`, `0x2ad7c0`: `{0,0,2,0}`, `{4,0,2,0}`, `{5,10,1,0}`. [C] The implementation appends, rather than clearing an existing descriptor vector. [C] `_Texture` is converted to a managed string and its property ID is stored at the state equivalent of global `0x40d150`; property block, command buffer, shader, material, mesh and font texture follow the observed create/construct/instantiate/pin ordering. [C] Asset names are the decoded `Assets/AssetBundleData/guish.shader`, `Assets/AssetBundleData/SystemUI.prefab`, `Assets/AssetBundleData/RenderTexture.renderTexture`, `RawImageUI`, `CameraUI` and `System.GUI`. [C] Direct literal recovery and cache evidence are in [decoded literals](/home/john/Desktop/cheat_re/dump_analysis/semantic_reconstruction/unity_backend/decoded_literals.json) and [cache evidence](/home/john/Desktop/cheat_re/dump_analysis/semantic_reconstruction/unity_backend/cache_specs.json).

[C] The shader reflection-type cache is initialized to numeric sentinel `0x402402` in DLL cell `0x27f9a8`. [C] `0x375ad8..0x375af5` replaces it through class/type/reflection-object calls only while it equals that sentinel; a resolved zero is not retried. [C] This cache is separate from the `LoadAsset_Internal` method-pointer cell `0x402c18`, whose flags are at `0x402c20`. [C] The implementation preserves both lifetimes. [I] The owned backend starts with the native command-count initializer **1** from `0x27fa54`; defaulting it to zero would introduce a first-frame mesh clear/subMeshCount setter absent from the one-command native path.

[C] `0x3b3240` reads `IO+0x50`, obtains font pixels, creates Texture2D with format4 and both booleans false, pins it, and sets filter mode0. [C] `0x3b27b4` queries writable image data before image-data size. [C] Row byte count is a wrapping signed32 multiplication of width and bytes-per-pixel (`0x3b3312`); row `y` is copied to destination row `height-y-1` (`0x3b3320..0x3b334d`). [C] The code applies the texture with `{true,false}` and writes the font atlas texture ID (`0x3b3f30` is the plain `atlas+8` store). [I] Native memcpy is replaced by checked owned-buffer copying plus a synchronous writeback callback. [U] Negative, overflowing or undersized copied image buffers stop with an explicit analysis status rather than attempting native undefined/out-of-bounds behavior.

[C] Submission always clears CommandBuffer (`0x3b304e`) before reading mesh `+0x10` (`48 83 78 10 00` at `0x3b305a`). [C] Missing native mesh data accumulates delta time while retry time is **at most**3; a strictly greater timer causes resource creation and then timer zeroing, with an immediate return either way (`0x3b3069..0x3b3091`). [C] It does not submit in the same invocation as resource recreation. [C] Screen height getter is `0x2e09f0`; width getter is `0x2e0af0`. [C] Changed screen dimensions release, set width, set height, create the RenderTexture and update RectTransform size before bounds are replaced (`0x3b1904`). [C] Draw viewport is DisplaySize multiplied by FramebufferScale; the zero-dimension and `total_vertices==0` gates follow the resize path. [U] Native NaN acceptance in these COMISS guards is not attributed to the existing finite-coordinate offline planner, which explicitly reports malformed inputs.

[C] Mesh upload reuses the checked `flatten_geometry_3b4250` helper in [02_rendering.cpp](/home/john/Desktop/cheat_re/source/reconstructed/02_rendering.cpp). [C] A changed command count clears Mesh with `true`, stores the count **before** invoking its setter, then configures vertex and index counts. [C] Injected wrappers replace the managed object with its copied `+0x10` native pointer after cache setup and before the leaf call; the submesh call includes its literal start0 argument. [C] Every list uploads its original buffers with cumulative destination offsets, stream0, source-start0, strides20/2 and flags15 (`0x3b4327`, `0x3b4369`). [C] Each native 48-byte submesh descriptor has zero center/extents, topology0, index start/count and base vertex from the existing concatenation helper, plus zero firstVertex/vertexCount (`0x3b43f9..0x3b4426`). [C] The final submesh-array call is followed by UploadMeshData(false), including for an empty list set.

[C] Recording reuses `plan_render_commands_3b1a94` for clip subtraction/scaling and retained submesh ordinals. [C] It constructs the RenderTargetIdentifier, sets the render target, clears color and depth to zero, sets viewport, constructs the view translation matrix, obtains the Unity Ortho result through a required callback, then sets view/projection. [C] Accepted draws set property-block texture, enable scissor and DrawMesh with global identity matrix, cached material, retained submesh ordinal, shader pass-1 and property block. [C] Scissor is disabled after all lists, even if no command survives clipping. [C] Graphics.ExecuteCommandBuffer occurs only after all upload/record calls complete. [C] The identity global's initializer is `0x2c3794..0x2c388c`, using `1.0f` at `0x28d254`; the DLL's uninitialized global bytes alone are all zero and are not sufficient evidence of its runtime value.

[C] Wrapper caches set bit1 before invoking the resolver and bit2 before the detection-only context callback. [C] Reentry or failure therefore observes already-set bits. [C] `prepare_unity_cache` keys storage by the exact flag-cell RVA, preserving shared-cell identities. [C] Icall wrappers also prepare the local il2cpp_resolve_icall wrapper cache (`0x3b4d28` or `0x376154`) before resolving their requested icall. [I] The generated [cache catalog](/home/john/Desktop/cheat_re/source/reconstructed/unity_backend_cache_specs.inc) gives exact wrapper/flag/target/context/resolver cells, signature hashes and literal roles. [C] `resolve_unity_backend_target` routes signature resolution to the existing `resolve_signature_333d10` and class/parameter/direct-export selection to existing metadata interfaces. [C] The `0x333bf4` callers here pass parameter index-1, so selection returns the first matching valid-range method/name and ignores the passed count and parameter name; this includes the apparently specific `"rt"` argument in `0x3b3c90`. [C] The separate `0x3b106c` constructor scan requires `.ctor`, count1, and a parameter type-name suffix `Texture` after the final `.` or `+`. [C] IO update stores unscaled delta and camera pixelRect width/height before checking Mouse.current. [C] Mouse controls are copied from control `+0xf8`; Y inversion uses **Screen.height**, not camera pixelRect height (`0x3b3998`). [C] The scroll helper `0x38cd28` enqueues an ImGui input event; the implementation calls the supplied ImGui function instead of inventing an immediate mouse-wheel accumulator write. [C] Buttons are left, right, middle, back, forward. [C] On an invalid vector-control pointer, `0x3b34f0` calls `0x2cb3a4`, whose bytes are `48 8b c1 c3` (identity). [C] The frame controller performs setup before all eight lazy bundle loads and the original LateUpdate. [C] Each bundle loader allocates/copies its source to owned managed-array payload storage, preserving a retry on zero bundle. [C] The original-call cache is prepared before the original-call adapter; the bundle0 early return follows that call. [C] The disconnected getter `0x2e0e4c` is intentionally called three times, allowing different results and preserving the clear/return branches. [C] Finalization and submission also occur during active splash.
