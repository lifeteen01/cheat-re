## Interface and composition

[I] `GameInputKeyStore` is authoritative shared edge history. Warm native once-state requires explicit corresponding owned-state import. The module never invents an empty key map when the flag says it already exists. Numeric bucket/sentinel/node addresses and native allocator counters are not fabricated. The existing registry's `baseline_hash_2d0ae4` implements the identical raw four-byte FNV chain2cf0e4→2d553c→2d6fa0→2d0ae4. Default insertion stores key32 and valuebyte0, preserves complete signed key IDs, maintains bucket/list order and performs the native initial8→64 growth under the normal load-factor condition. Raw node padding is not represented as initialized data. [U] Native heap allocation/free failure prefixes, invalid/malformed imported native headers, impossible host-container sizes and native trap/error dispatch remain library/resource backlog under the changed task priority.

[I] `GameInputStackEvidence` separates ACTUAL copied pointer/padding bits from typed values. `GameInputCall` carries optional dispatcher/target keys, a required context key, eight per-argument byte masks, the unmaterialized type-byte mask and the return-pointer flag. A bit means that native source byte has not been materialized. Such destination bytes retain their old Snapshot backing and must not be consumed as known raw values. Supplying actual evidence writes those bytes at the original store stage. Supplying numeric zero is distinct from absence. Each packing invocation resets its evidence masks, so reusing a descriptor does not carry a previous call's materialized stack bits into the next call. No host pointer, generated stack address or gadget chain is used.

[I] Raw `game_input_pack_*` functions perform the known stores; `game_input_apply_3214f4`, `game_input_apply_32225c`, and `game_input_apply_2e480c` additionally require and consume the typed final effect. `GameInputSixArguments.fourth` is optional; `fourth_text` can retain the caller's known owned text while its original pointer bits remain unmaterialized. Actual runtime text/ABI conversion is a required adapter, not an invented numeric string address.
