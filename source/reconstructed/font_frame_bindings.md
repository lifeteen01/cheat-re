# Frame font and failure composition

[C] [I] [font_frame_bindings.cpp](/home/john/Desktop/cheat_re/source/reconstructed/font_frame_bindings.cpp) binds frame roles `36135c`, `361bcc`, `3a31f8`, `3a31bc`, `3a3874`, `38f79c` and `391c50` to the concrete text controllers, rasterizer and measurement code. The `3a31bc` wrapper retains font0/size0 defaults, zero wrapping and no fine clip before calling `3a31f8`. Actual copied metrics/glyphs and initialized drawlists remain required data. `bind_world_font_measurements()` and the frame measurement roles use authoritative `FontTextStore` metrics for generated fonts, avoiding stale Snapshot vector descriptors after an owned atlas build. Native current-font keys and sizes are still read from copied context fields.

[I] `FontFrameStorage` reserves independent copied string-object, character, position and color regions. Owned frame strings are staged using the consumed MSVC string layout; native allocation/capacity ABI is adapted. Text-end results use numeric addresses within the reserved character region. This distinguishes a null end from a valid end at byte0, including labels beginning with `##`. Those numeric addresses are data only and are never executed or cast to host pointers.

[C] Controller font-size writes to Snapshot globals `248ed0/248ed4/248ed8/3fa7c0` are copied back into `FrameMenuState.values` after success and after a nested failure. This keeps subsequent preview/raid reads coherent with earlier native stores. The original initial-font argument remains unused where the native controller ignores it; the fallback font record remains the first controller argument. Color remains copied memory so final-pass color rereads remain observable.

[C] [Fixtures](/home/john/Desktop/cheat_re/source/reconstructed/font_frame_binding_checks.cpp) verify centered/plain geometry, each relevant font-size output, `##` text-end handling, direct measurement and output synchronization after a missing-font failure. Focused [strict](/home/john/Desktop/cheat_re/dump_analysis/semantic_reconstruction/font_text/frame_binding_verification.txt) and [sanitizer](/home/john/Desktop/cheat_re/dump_analysis/semantic_reconstruction/font_text/frame_binding_sanitizer_verification.txt) checks pass. [I] Reproduce using [build_frame_bindings.sh](/home/john/Desktop/cheat_re/dump_analysis/semantic_reconstruction/font_text/build_frame_bindings.sh).

[C] [frame_failure.hpp](/home/john/Desktop/cheat_re/source/reconstructed/frame_failure.hpp) propagates typed snapshot/metadata failures and renderer stop sites through frame controller result objects without rolling back prior mutations or resetting accepted/rejected counts. The generic renderer exception lacks a separate byte/type classification, so it is reported as a required dependency with its exact reached site. Frame/preview regression fixtures retain writes performed before the failing callback. [U] Expanded combined verification and further native/controller review remain separately tracked.

[C] Native `391c67` looks ahead one byte when testing `##`, even when the next byte lies beyond an explicit text-end marker. The copied-font and owned-font current-text measurements preserve that cutoff; boundary regressions cover `A##ID` with its explicit end at the second hash.
