[I] `HelicopterAimState` owns the helicopter target and projectile-speed globals; existing `AimState` supplies prediction-table context and compensation. The context argument is overwritten before use in the native body. Numeric addresses are copied-memory keys and are never called or dereferenced as host pointers.

[C] The worker validates local and helicopter receivers, selects bone 62 or 63 using the literal health threshold, reads origin and held item, and queries all four weapon classifiers before choosing thrown, server-projectile, melee-projectile or ordinary-projectile behavior, in that priority order. The initial health helper `0x36970c -> 0x2dee3c` is concrete: a checked float read at target `+0x2cc`. Special projectile helper `0x36b504` is concrete: a fresh `+0x3ac` read followed by binary32 `+1`. The pointer predicate `0x2caf08`, zero-vector construction/comparison, normalization `0x2e1278 -> 0x2e0ee8 -> 0x2e3c88`, vector scale/add/subtract and two-component scale/add/subtract are concrete. Existing literal angle, repeated-wrap and single-wrap implementations are reused.

[C] `COMISS 5000, health; JB` skips bone 63 on an unordered health result; equality chooses bone 63. Exact-zero comparisons accept signed zero and reject NaN. Native `MINSS` velocity caps select the constant second operand on unordered input. Attachment equality with zero skips the second getter; every nonzero or unordered result repeats `0x36b758`, including when global `0x3e4238` is set. Attachment equality with 1.3 takes the `JAE` path. The ordinary projectile branch stores `0x3e5e74` before testing the captured table pointer, and the latter is loaded before that store. Thrown formatting and destruction remain ordered; missing table state still destroys the formatted value before returning.

[C] Failed intermediate subtype getters reach the common angle tail with the original target point; zero prediction also retains that point. The tail reloads target-helicopter, silent and active flags after callbacks. It captures old angles, computes/wraps their delta, adds it to old angles, optionally subtracts parent Euler yaw, and optionally multiplies the wrapped delta by smoothing before adding old angles. Its final `input+0x44` and `input+0x48` stores are independent and ordered. Shared aim marker/motion globals are not written by this worker.

[I] `bind_helicopter_aim(snapshot, shared, helicopter, config, calls)` returns an `AimWeaponCalls` copy with `helicopter_2fa300` connected to the replay. The closure borrows the four referenced objects and captures the dependency callbacks by value. [C] Reached copied-byte, missing-callback and nonprogressing-wrap failures propagate as `SnapshotBindingFailure`; the existing outer aim controller catches that type. Successful return lets the caller perform its own subsequent marker clear. [I] Missing copied data stops where first reached; writes before a later failure remain visible. No rollback or synthetic destructor is added to a reached dependency failure.
