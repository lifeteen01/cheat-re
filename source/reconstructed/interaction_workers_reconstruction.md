## Replay assumptions and limits

[I] `InteractionConfig` is copied on entry. This freezes configuration/global input values over one call. `InteractionState` and `Snapshot` remain owned mutable state, including cross-call timers, latches, frame counter and dispatch caches. [U] Native concurrent config mutation, reentrant callbacks changing those captured globals, live pointer dereferences, floating-point exception flags/rounding/denormal controls and game/server behavior are not asserted.

[U] Invalid destination getter branches at `0x2e7e82..0x2e7e96` and `0x2e8046..0x2e8058` consume stale stack +0xa0 as UID and count. The caller must supply those actual copied 64 bits via `destination_scratch`; otherwise replay returns `stale_stack_required`. An invalid repeated orientation getter similarly reports the unwritten-temporary dependency. [I] Loop limits stop malformed/callback-expanded inputs explicitly and are not native protections. Native uint32 wrapping followed by MOVSXD for item-array index multiplication is preserved using defined C++ arithmetic.
