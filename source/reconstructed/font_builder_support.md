# Font builder cleanup and opacity helpers

[C] [I] [font_builder_support.cpp](/home/john/Desktop/cheat_re/source/reconstructed/font_builder_support.cpp) translates six local bodies used by the atlas builder: pixel release `3a3e64`, font output clear `3a3e10`, vector release `379578`, config initialization `3a5950`, opacity-table creation `3a4d18`, and per-pixel table application `3a4d50`.

[C] Pixel release rereads the RGBA pointer after releasing Alpha8; both pointers and the ready byte are cleared only after the effects. A nonnull vector's size/capacity is cleared before release and its data pointer afterward; a null data pointer leaves the existing size/capacity bytes untouched. Font config setup clears output before rereading the nominal size, preserving aliases between config and font. Merge mode skips clearing and wraps the config-count WORD.

[C] Opacity LUT creation uses native binary32 multiplication, CVTT64, then an unsigned comparison of only the result's low32 with255. Negative and nonfinite values therefore preserve the sample's unusual results rather than using a conventional float clamp. Application preserves signed32 address arithmetic, row stride and sequential LUT/pixel aliasing. Missing copied bytes stop with prior writes retained. [I] Explicit row/pixel bounds prevent pathological analysis loops; no native bounds are attributed.

[I] `free_39517c` is an owned release adapter and can bind the existing concrete `draw_core_free_39517c`; it never executes copied numeric code. These helpers update Snapshot bytes. Consumers must reimport font/atlas views if they also hold separate owned metric containers. [U] The full default atlas builder, parser, metric generation, packing and glyph raster closure remain separately assigned local work.

[C] [Fixtures](/home/john/Desktop/cheat_re/source/reconstructed/font_builder_support_checks.cpp) cover reentrant frees, failed vector release, null-vector retained bytes, merge-count wrapping, config/font aliasing, exceptional CVTT64 LUT values, LUT aliasing and negative stride. [I] Reproduce using [build_support.sh](/home/john/Desktop/cheat_re/dump_analysis/semantic_reconstruction/font_producer_inventory/build_support.sh), with `sanitize` for instrumentation. The shared [audit script](/home/john/Desktop/cheat_re/dump_analysis/semantic_reconstruction/unity_math/audit.py) regenerates the [byte ledger](/home/john/Desktop/cheat_re/dump_analysis/semantic_reconstruction/font_builder_support/audit.json).
