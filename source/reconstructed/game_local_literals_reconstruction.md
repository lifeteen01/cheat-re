[I] These are offline, analyst-authored C++20 routines over owned `Snapshot` copies and supplied typed effects. Numeric addresses are copied-data keys. No copied DLL instruction, numeric function pointer, game process, network operation or context/spoof executor is run. Context observation remains detection-only.

[C] Constructors retain native operation order, native-width span checks, instruction sites and interleaved static loads. Register payloads are owned bytes, and output projection uses optional bytes so a failed store does not invent its unknown suffix. A later failing DWORD store leaves a preceding QWORD committed and the entire failing DWORD untouched. Optional actual mapped aliases preserve source/destination overlap: for getter `3302b0`, source `294c08` and destination `294c0a` in the same Snapshot, the earlier DWORD store changes the later WORD load. Its native result is unterminated `Flesgu`, rather than a flattened-copy `Flesh`.

[C] Converters test their actual last-byte guard before decoding. Reached loops XOR each byte with `(i % 56) + 55`. The generator independently verifies the recovered multiply/divide quotient for every reached loop counter before using remainder arithmetic. Zero guard skips decoding. A producer may return an unterminated buffer; its `terminated` flag reports only a NUL inside known constructed bytes. String consumers stop when a required suffix is not mapped or known. They do not synthesize a terminator.

[C] Name hashing and seeded literal hashing reuse `entity_name_hash_2d6354` from the released entity module. This is 64-bit FNV with sign-extended input bytes, not unsigned-byte FNV. The supplied seed is preserved. `3ca884` comparison reads right then left, streams until a difference or NUL, and returns the difference of signed 8-bit values. A first-byte mismatch can succeed without a mapped trailing classname NUL. Literal writes happen before a subsequent missing classname read, and therefore survive that failure.

[C] Managed conversion reuses the released direct wrapper's exact `2ce5dc→2ce718` cache, metadata-export, context-observer, dispatcher reread and argument-staging logic. Mapped literal text is reread at the final typed string leaf after observer mutation. Owned text requires a known terminator at that same point, after the concrete staging prefix. The projectile binder converts metadata argument failures to `SnapshotBindingFailure`, preserving status, exact failing instruction and prior writes, so the enclosing replay can report its existing typed failure.
