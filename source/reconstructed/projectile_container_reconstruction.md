The global at `0x218978` contains vector begin/end at offsets0/8. Lookup `0x32b838` walks pointer slots forward, rejects numerically invalid projectile keys and compares each projectile's raw DWORD at `+0x138` (`0x3742ac`).

[C] Native conversion `0x2d4060` copies a DWORD; it does not produce a string. Helpers `0x2d7d90/0x2d87b0` expose begin/end. The worker retains the matched iterator at stack `+0x78`, reads its projectile pointer, and passes that same iterator to `0x32cb8c` after the launch mutations. [I] Earlier descriptions calling this a map/string conversion are superseded by these literal vector semantics.

[C] Erasure shifts the following pointer bytes toward the matched slot, reduces end by8 and returns the erased slot. The `0x2ce5a4` branch predicate is a constant-zero stub, selecting the `0x2d9b1c → 0x2da100 → 0x2d0b64 → 0x3c8d4c` copy path. [I] C++ expresses the valid aligned overlapping copy with forward qword reads/writes; partial failures of malformed snapshots are analysis results, not a claimed native memory-fault ABI.

[C] The projectile worker now accepts `lookup_shot_entry` and `erase_shot_iterator` callbacks that retain that exact slot. `bind_projectile_container` supplies both concretely. [I] Legacy ID-only callbacks remain available for existing standalone consumers, with weaker iterator identity. New bindings throw a typed RVA/status failure on missing data; the worker translates it into its public result.
