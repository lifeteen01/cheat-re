Source evidence belongs in the catalog metadata, outside this configuration schema.

[I] There are **219 named entries**: **142 field contexts** covering **77 distinct historical field start values**, and **77 native GameAssembly reference sites** covering **64 distinct historical RVAs**. The inventory's 141 deduplicated numeric values therefore expand to separate names when receiver or reference context differs. No unsupported SDK field names have been invented.

- [I] Other `field.<context>.<historical field start>` keys preserve the CSV's descriptive contexts where no SDK identity is established.
- [I] `gameassembly.site_<cheat instruction RVA>` identifies one native fixed-input reference. This suffix is a site in the cheat, while its configured `value` is an RVA in GameAssembly.
