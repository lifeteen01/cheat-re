## Confirmed literal differences, already declared analysis adaptations

[C] **S1 — defensive PE/export reading is not a literal native resolver.** Source: `03_stack_spoof_spoofcall.cpp:6`–17, 33–48, 187, 210. Native resolver `[0x2ce7c8,0x2ce84c)`, header leaf `[0x2ce7c0,0x2ce7c8)`, and exception reader `[0x2ce1d4,0x2ce1ee)`. Trigger examples: a named function RVA is zero or lies within the export directory; an unmatched earlier name has an ordinal outside NumberOfFunctions; MZ/PE/magic is malformed despite copied field/table bytes being available; declared directory extent is not wholly copied despite the selected runtime record being copied.

[C] Native `0x2ce7c8` searches names forward using exact byte equality (`0x2cc6a8`), reads an ordinal only after a name matches, and returns `module_base + function_RVA` directly, including base for zero RVA and a numeric forwarder address for an RVA inside the export directory. It does not read NumberOfFunctions for ordinal validation or validate MZ/PE/magic/declared directory extent. `find_export` deliberately rejects those cases, validates every visited ordinal before name comparison and imposes string/name bounds. `directory` also reads unsigned e_lfanew, where native readers use MOVSXD. [I] Returning a numeric forwarder value as evidence would not require executing it. The current behavior is explicitly called defensive/analysis code and forwarder/null exclusion is documented, so this is not filed as an undisclosed implementation bug. [U] `audit_context_metadata` consequently cannot claim equivalence of native metadata acquisition on all supplied snapshots.

[C] Missing literal local metadata ranges remain `[0x2ce130,0x2ce1d4)` (module/export acquisition orchestration) and `[0x2ce7c8,0x2ce84c)` (export resolver), if the completion ledger requires literal source for these rather than the declared conventional reader. [I] A completion decision must preserve that distinction. The native caller's unchecked missing-entry dereference is intentionally replaced by explicit unavailability.
