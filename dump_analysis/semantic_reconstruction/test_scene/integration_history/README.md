# Historical integration inputs and failed attempts

The Markdown files here preserve the pre-integration scene records. They describe
older selected-page/worker or focused checkpoints and are not current-source PASS
evidence. The current source/test_scene records and final_audit.json supersede them.

sanitizer_timeout_180 retains the initial final-root sanitizer attempt that exceeded
the old180-second bound. It is explicitly incomplete/failed. Later completed mode
verification records must match current sources, runner and artifact hashes.

Other integration_*.log/gdb/probe artifacts in the parent scene evidence directory
are diagnostics from intermediate attempts, not final verification verdicts.
